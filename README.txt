# Nowshehra Waters — Frontend Website

A responsive frontend implementation based on the supplied Nowshehra Waters brand board and the requested UI.

## Included
- Responsive homepage
- Product cards: 330ml, 1.5L, 5L and 19L
- Online ordering UI
- Counter Sale option on every product
- Quantity controls
- Frontend cart counter
- Home-delivery order form
- WhatsApp order button
- Purification process
- About section
- Reviews
- Contact section
- Mobile navigation
- Scroll reveal animations
- Branded image assets cropped from the supplied design
- UI reference image included in assets/ui-reference.jpg

## Run
Open `index.html` directly in a browser, or put the folder in XAMPP:
C:\xampp\htdocs\nowshehra-waters\

Then visit:
http://localhost/nowshehra-waters/

## Important
This is the complete frontend/UI layer. The cart, order form, counter-sale action and contact form currently use JavaScript demo behavior. For a production system, connect them to PHP/MySQL for products, customers, orders, payments and admin management.
